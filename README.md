# 数学擂台 · 试玩版

高一「集合与逻辑」单人答题原型。对手由本地程序模拟，**没有真实在线双人对战、教师建赛、匹配、房间、排行榜或淘汰赛**；这些仅是后续方向。

## 使用

双击 `index.html` 即可离线运行。无需 App、登录、数据库、后端、密钥或外部 CDN。手机和电脑均可打开；页面采用响应式布局，关键按钮支持触屏、键盘和焦点指示。

实际游戏网址：**[点击开始试玩](https://lizekun250.github.io/lizekun250-math-arena/)**。

源码仓库：[lizekun250/lizekun250-math-arena](https://github.com/lizekun250/lizekun250-math-arena)。GitHub托管代码，GitHub Pages提供实际游戏页面。

## 玩法和试验参数

首页点击“开始挑战”，每局随机排列题库，最多 12 题。模拟对手 100 HP，击破、本局 5 分钟用完或题目用完即结算。总局计时包括阅读解析时间。对手为被动训练靶，不会攻击玩家。首题连续答对倍率 ×1.00，之后依次 ×1.10、×1.20、×1.30、×1.40，第 5 题之后封顶；答错与超时归零，下一次答对重新从 ×1.00 开始。

连击伤害 `floor(B × 倍率)`，速度奖励 `floor(B × 0.15 × (1-clamp(t/T,0,1)))`，最终伤害为两项相加。速度奖励只按基础伤害计算，不乘连击。每题提交立即锁定，读完解析再进入下一题。后台恢复后以真实时间判断截止时间，不依赖定时器回调次数；在截止时间及之后提交均判超时。

胜利时末题解析保留在结算页面，末题伤害可能大于对手剩余 HP；界面分开显示累计理论伤害与有效扣血。

## 修改与维护

- 游戏配置集中在 `index.html` 的 `<script id="game-config" type="application/json">`，可修改 HP、每局题数、总时限、连击表、速度奖励率及随机排序。
- 题库源文件 `high_school_sets_logic_v01.json` 是用户原有文件，本次保留原样。每题基础伤害和答题时限均集中在该 JSON 中，修改后执行 `npm run build` 同步到独立 HTML。
- 数学核验记录见 [QUESTION_REVIEW.md](QUESTION_REVIEW.md)。填空严格使用标准答案和已列等价形式；没有近似容差和表达式自动求值。
- 网页仅用原生 HTML/CSS/JavaScript，全部 CSS、题库、规则及界面代码均在 `index.html` 内。上线后二维码也内嵌为 data URL；单文件下载后无需额外图片即可分享。
- `dist/` 是静态发布目录。`node scripts/build.mjs` 无需安装依赖即可打包；无需前端框架、打包器和编译流程。根目录文件是可直接运行的正式交付源文件。

直接运行HTML无需Node.js。打包脚本可用Node.js 20+，当前测试和二维码开发工具需要Node.js 22.22.2+、24.15.0+或26+（详见package.json）：

```sh
npm ci
npm test
npm run build
npm run serve
```

测试与二维码工具仅是开发依赖，不参与学生端运行。详情见 [TEST_REPORT.md](TEST_REPORT.md)。

中国大陆部署、域名备案和费用分析见 [DEPLOYMENT.md](DEPLOYMENT.md)。当前用户无国内云、域名和备案条件，本次只交付公网演示，不把单次可访问性当作全国稳定访问证明。不购买域名，不开通付费服务。

## 隐私与边界

页面不收集姓名、手机号、学校、位置或答题记录，不用 Cookie、本地持久化存储、分析 SDK 或外部 API。答题状态仅保留在当前页面内存中，刷新即清除。托管平台可能有自己的标准访问日志，页面并不控制平台日志。前端题库可在源码中查看，因此不适合作为防作弊的正式考试系统。

教师建赛与在线 1V1 需要后续设计服务器判题、连接同步、身份和房间、断线恢复及隐私边界，当前均未实现。
